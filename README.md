# 赖子麻将（石首十三张 · 单机练习版）

竖屏手机网页版单机赖子麻将：玩家 + 3 家电脑，带出牌提示（含理由）和教学模块，适合练牌。
手机直接打开网址可玩 https://bk2gf59w5d-ui.github.io/laizi-mahjong/

## 玩法规则

- 牌：万、条、筒各 1–9，共 108 张。每人 13 张，庄家 14 张。
- **赖子**：每局翻开一张牌（赖子皮），其下一张为赖子（如翻 7 万则 8 万为赖子，9 万翻后 1 万为赖子）。
- **赖子皮只有 3 张**：翻出的那张移出游戏，剩余 3 张在牌局中流通。
  - 手牌凑齐 3 张赖子皮 = 宣告**暗杠**（每家 2 分），只亮 3 张、**不补牌**，打出一张继续行牌；也可选择不杠直接和牌。
  - **没有回头杠**（加杠）——赖子皮成杠后不能再添第 4 张。
- 赖子可当**万能牌**使用，也可当**它本身**使用；最多用 1 张万能牌替代。
- **赖子永远不能打出**，只能"亮赖子"（翻开明置，算作和牌张数）：每亮 1 个赖子，和牌分 ×2；亮 2 个 ×4。手里有赖子时"亮赖子"按钮始终可用（可选）。
- 可碰不可吃；无七对、无十三幺。
- 和牌：**自摸**和牌（4 组 + 1 将），手里持有赖子时倍率再 ×2（未用万能牌）或 ×1（用了万能牌）。
- 杠牌计分立即结算：暗杠每家 2 分；明杠点杠者出 2 分；赖子皮 3 张国杠按暗杠计。
- 流局：牌墙摸完无人和牌，庄家不变。

## 本地运行

```bash
npm install
npm run build   # 产物在 dist/
npm run dev     # 开发调试，端口 3000
```

## 部署到 GitHub Pages

项目已配置 `base: './'`，可直接用 GitHub Actions 部署：仓库 Settings → Pages → Source 选 "GitHub Actions"，push 到 main 自动构建发布，地址为 `https://<用户名>.github.io/laizi-mahjong/`。
